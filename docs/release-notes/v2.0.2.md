# v2.0.2 · 服务与配置迁移

日期：2026-11-26

## 版本说明

本 fork 以 LianXia233 上游 v2.0.2 为基础，完成从旧版 `at-webserver` 服务体系到 `mt5700d` 单包架构的迁移。此次是架构升级，不是普通的小版本覆盖。

## 主要变化

- Rust 常驻服务、可执行文件、UCI 配置段和 LuCI 静态资源统一使用 `mt5700d` 名称。
- 旧版 `/etc/config/at-webserver` 在解包前备份，迁移到 `/etc/config/mt5700d`；已核对旧版配置项均有对应项。
- 迁移旧短信归档目录与流量持久化文件；新版短信归档读取器兼容旧容器格式。
- 清理旧服务注册、旧二进制与旧防火墙规则，避免旧进程继续占用 PC UI 串口。
- 保留普通 / 极简双 UI、原有业务页面与 fork 页脚署名；保留 fork 原分支的四张背景图文件，不采用上游替换后的版本。
- RPC 提示明确区分监听范围与防火墙权限：监听所有接口时只自动放行 LAN，不自动开放 WAN。

## 升级保护

- UCI 备份失败时，preinst 中止升级。
- 配置迁移采用临时文件转换后再替换目标；失败时保留旧配置备份。
- 短信归档、流量记录迁移失败，或检测到旧版串口进程仍在运行时，迁移脚本返回失败并阻止新版服务启动。
- `uci-defaults` 在迁移失败时保留脚本，供下次开机重试。
- 如果设备同时存在新旧配置文件，保留新配置并将旧配置另存为 `.pre-migration`，不静默覆盖。

## 串口兼容性

自动探测优先识别 MT5700 的 PC UI / PCUI 接口，支持 `3466:3301` 设备，并优先使用 `/dev/serial/by-id` 稳定路径；没有稳定路径时回退到 `ttyUSB*` 等串口节点。默认波特率保持 115200。

## 验证状态

本版本仍须完成以下验证后才可正式发布：

1. GitHub 静态检查、Node 单元测试、ShellCheck、Rust 测试与 Clippy、mock 模组端到端测试。
2. OpenWrt 25.12 APK 与 24.10 IPK 多架构 SDK 构建。
3. 在 MT5700M-CN（USB VID/PID 3466:3301）设备上验证升级前配置、短信历史、流量累计、PC UI 串口、拨号和重启自启。
4. 确认升级后没有旧 `at-webserver-rust` 进程残留。

在以上检查完成前，不应将此迁移分支视为已通过实机验证的正式安装包。
